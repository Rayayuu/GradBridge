# CS 学期规划模板

大学规划最容易出现的问题，是每个方向都单独规划：

- 课程一个计划
- LeetCode 一个计划
- 项目一个计划
- 求职又一个计划

最后时间完全冲突。

更合理的是把所有事情放进同一张 Semester Plan。

## 第一步：只定 3 个核心目标

建议一个学期最多三个核心目标。

例如：

```text
Goal 1: 所有课程稳定完成
Goal 2: 做完一个 Backend Project
Goal 3: 为 Internship 准备 CV + Coding
```

## 第二步：规划能力资产

| Area | 本学期目标 | 最终产物 |
| --- | --- | --- |
| Study | 完成核心课程 | 成绩 + 知识笔记 |
| Tech | 学 Backend | 一个可运行 API |
| Project | 完成团队项目 | GitHub Repo + Demo |
| Career | 准备 Internship | CV + Tracker |
| Interview | DSA 高频题 | 题型总结 |

## 第三步：按时间切阶段

### Week 1–4

- 建立课程节奏
- 确定项目
- 补基础

### Week 5–8

- 项目进入主要开发
- Mid-semester Assessment
- 开始整理 CV

### Week 9–12

- 完成项目
- 准备 Final
- 开始下一阶段申请

## 第四步：每周 Review

每周只问四个问题：

1. 本周真正完成了什么？
2. 哪件事花了很多时间但价值很低？
3. 下周最重要的一件事是什么？
4. 有没有 Deadline 正在靠近？
