# 海外 CS 四年 Checklist

这份 Checklist 的目标不是让你四年把所有东西都做完。

> 它的作用是帮助你判断：现在最值得做的事情是什么。

## 大一：建立基础

- [ ] 熟悉至少一门主语言
- [ ] 掌握 Git 基础操作
- [ ] 能独立完成课程 Programming Assignment
- [ ] 理解 Array、Linked List、Stack、Queue、Hash Map
- [ ] 开始维护 GitHub
- [ ] 做至少一个可以展示的小项目
- [ ] 学会阅读 Documentation
- [ ] 保持基本成绩，不因为求职完全放弃课程

## 大二：从课程走向工程

- [ ] 掌握 OOP
- [ ] 学会 SQL 和基础 Database
- [ ] 理解 HTTP / REST API
- [ ] 完成一个多人 Group Project
- [ ] 学会 Pull Request 和 Code Review
- [ ] 开始准备 LeetCode 高频题型
- [ ] 把课程项目整理成 CV Bullet
- [ ] 开始关注 Internship Timeline

## 大三：进入求职主战场

- [ ] 完成一版正式 CS CV
- [ ] LinkedIn 信息完整
- [ ] GitHub 有 2–3 个能够讲清楚的项目
- [ ] 建立 Internship Application Tracker
- [ ] 系统准备 Coding Interview
- [ ] 系统准备 Technical Interview
- [ ] 准备 Behavioral Stories
- [ ] 大规模投递 Internship / Graduate Program
- [ ] 主动参加 Networking / Career Event

## 大四：完成转换

- [ ] 明确 Graduate / Full-time 求职方向
- [ ] 根据岗位重新调整项目展示
- [ ] 能完整讲清一段 Internship / Project Experience
- [ ] 能进行 45–60 分钟 Technical Interview
- [ ] 能回答 Why this company / Why this role
- [ ] 持续记录所有申请状态
- [ ] 准备毕业后的 Work Rights / Location Plan

## 每学期都检查

- [ ] 这学期最重要的能力是什么？
- [ ] 有没有一个可以留下来的项目产物？
- [ ] 有没有一个可以写进 CV 的结果？
- [ ] 有没有认识新的同学、工程师或导师？
- [ ] 有没有在为下一阶段提前准备？

## 不需要同时做到的事

你不需要同时：

- 刷 500 道 LeetCode
- 学 8 个 Framework
- 做 10 个项目
- 保持极端高 WAM
- 每周参加 Hackathon

更重要的是建立一条连贯主线。
