# CS CV Checklist

在投递之前，用这份 Checklist 做最后检查。

## Header

- [ ] 姓名明显
- [ ] Email 正常且专业
- [ ] Phone 正确
- [ ] LinkedIn 可访问
- [ ] GitHub 可访问
- [ ] 不放无必要的私人信息

## Education

- [ ] University 和 Degree 写清楚
- [ ] Graduation Date 正确
- [ ] WAM / GPA 只有在有价值时展示
- [ ] Relevant Coursework 不要堆太多

## Experience

- [ ] 每条 Bullet 以 Action 开始
- [ ] 说明做了什么
- [ ] 说明用了什么技术
- [ ] 尽量说明结果或影响
- [ ] 不只是 Job Description

## Projects

- [ ] 至少有一个能深入讲的项目
- [ ] 技术栈和贡献明确
- [ ] 不写“Responsible for”式空话
- [ ] GitHub / Demo 可访问时提供链接

## Skills

- [ ] 只写真的能够讨论的技术
- [ ] Language / Framework / Tool 分类合理
- [ ] 不使用百分比或进度条表示熟练度

## ATS

- [ ] 使用标准 Section Name
- [ ] 不依赖复杂双栏或图形元素
- [ ] PDF 文本可以正常复制
- [ ] Job Description 中的重要技术词有合理匹配

## 最终检查

- [ ] 一页优先，除非经历确实很多
- [ ] 没有拼写错误
- [ ] 时间格式统一
- [ ] Bullet 标点格式统一
- [ ] 文件名专业

例如：

```text
Firstname_Lastname_Resume.pdf
```
