# Software Interview Preparation Checklist

面试准备不要只刷 LeetCode。

一个完整 Software Interview 通常可能覆盖四类内容。

## Coding

- [ ] Array / String
- [ ] Hash Map / Set
- [ ] Two Pointers
- [ ] Sliding Window
- [ ] Stack / Queue
- [ ] Linked List
- [ ] Binary Search
- [ ] Tree / BFS / DFS
- [ ] Heap
- [ ] 基础 Dynamic Programming
- [ ] 能解释 Time / Space Complexity

## Technical Fundamentals

- [ ] OOP
- [ ] HTTP / REST
- [ ] Database / SQL / Index
- [ ] Session / JWT
- [ ] Redis / Cache
- [ ] DNS / TCP
- [ ] Git
- [ ] 基础 Security

## Project Deep Dive

- [ ] 项目解决什么问题
- [ ] Architecture
- [ ] 为什么选择这些技术
- [ ] 最困难的问题
- [ ] 一个 Bug
- [ ] 一个 Trade-off
- [ ] 如果重新做会改什么

## Behavioral

至少准备：

- [ ] Team Conflict
- [ ] Leadership
- [ ] Failure
- [ ] Difficult Problem
- [ ] Tight Deadline
- [ ] Feedback
- [ ] Learning Something Quickly

## 公司准备

- [ ] Why this company
- [ ] Why this role
- [ ] Job Description 关键技术
- [ ] 2–3 个准备问面试官的问题

## 面试前一天

- [ ] Camera / Microphone
- [ ] IDE / Browser
- [ ] Resume
- [ ] Job Description
- [ ] Interview Timezone
- [ ] 安静环境

> 面试准备的目标不是预测所有问题，而是保证常见问题出现时，你有稳定的思考框架。
