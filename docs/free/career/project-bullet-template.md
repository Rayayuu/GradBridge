# Project Bullet 模板

很多 CS 简历的问题不是项目差，而是写出来以后完全看不出技术含量。

## 基础公式

可以先从这个结构开始：

```text
Action + What you built + How you built it + Result / Purpose
```

## 模板 1：实现功能

```text
Built [feature/system] using [technology], enabling [user/business outcome].
```

## 模板 2：优化性能

```text
Optimized [component] by [technical change], reducing [latency/cost/error] by [result].
```

## 模板 3：后端项目

```text
Designed and implemented [API/service] with [framework/database], supporting [core workflow].
```

## 模板 4：AI / ML

```text
Developed [model/pipeline] using [model/framework] for [task], achieving [metric/result].
```

## 模板 5：团队工程

```text
Collaborated with [team] to build [system], contributing [specific ownership] through [engineering practice].
```

## 普通写法

```text
Used React, Node.js and MySQL to make a website.
```

## 改进后

```text
Built a full-stack booking platform with React, Node.js and MySQL, implementing authenticated booking workflows and persistent reservation management.
```

## 写完后检查

- [ ] 是否看得出你具体做了什么？
- [ ] 是否有技术细节？
- [ ] 是否能看出项目目的？
- [ ] 是否存在可以量化的结果？
- [ ] 面试官追问时你能解释吗？

## 不要强行造数字

如果没有真实 Benchmark，不要为了“量化”凭空写：

```text
Improved performance by 80%.
```

没有可信数字时，可以描述真实范围、规模或功能结果。

## 最后

> 好的 Bullet 不是更华丽，而是让陌生人快速理解你的技术贡献。
