# Internship Application Tracker

当投递数量超过十几个以后，仅靠记忆很快就会混乱。

建议每一个申请至少记录：

| Field | 作用 |
| --- | --- |
| Company | 公司 |
| Role | 岗位名称 |
| Location | 地点 |
| Applied Date | 投递日期 |
| Source | LinkedIn / Seek / 官网等 |
| Status | 当前状态 |
| Next Step | OA / Interview / Follow-up |
| Deadline | 下一步截止日期 |
| Contact | Recruiter / Referral |
| Notes | 特殊要求或反馈 |

## 推荐 Status

保持状态统一：

```text
Saved
Applied
OA
Interview
Final
Offer
Rejected
Withdrawn
```

## 每周 Review

每周检查：

- 本周投递多少？
- 哪些 Application 没有下一步？
- 哪些 OA 快到期？
- 哪些公司需要 Follow-up？
- 哪种岗位 Response Rate 更高？

## 为什么记录 Source

一段时间以后，你可以判断：

- 官网申请效果如何
- Referral 是否更有效
- LinkedIn / Seek 哪个渠道更适合
- 哪类岗位 Response 更高
