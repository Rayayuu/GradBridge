<section class="gb-career-section">
<div class="gb-section-label">CAREER ROADMAP</div>
<h2>求职不是一次投递，而是一条漏斗</h2>
<p class="gb-career-lead">真正需要优化的是每一个阶段的转化率，而不是单纯增加投递数量。</p>

<div class="gb-career-roadmap-grid">
<div class="gb-career-roadmap-card">
<span>01</span>
<h3>Build</h3>
<p>课程、技术基础、项目、GitHub 和第一份可以投递的 CV。</p>
<strong>Skills · Project · CV</strong>
</div>
<div class="gb-career-roadmap-card">
<span>02</span>
<h3>Apply</h3>
<p>发现岗位、判断匹配、追踪申请并持续获得市场反馈。</p>
<strong>Search · Apply · Track</strong>
</div>
<div class="gb-career-roadmap-card">
<span>03</span>
<h3>Interview</h3>
<p>OA、Coding、Technical、Project Deep Dive 和 Behavioral。</p>
<strong>OA · Technical · STAR</strong>
</div>
<div class="gb-career-roadmap-card">
<span>04</span>
<h3>Convert</h3>
<p>把真实反馈继续转化成下一轮 CV、项目和面试能力。</p>
<strong>Review · Improve · Offer</strong>
</div>
</div>
