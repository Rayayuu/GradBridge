# 澳洲 CS 求职平台怎么用

求职平台的作用不是让你每天无目的刷新。

真正有效的方式是建立一个稳定的岗位发现系统。

## 第一层：公司官网

对于明确想去的公司，优先关注官方 Careers 页面。

特别是：

- Graduate Program
- Internship Program
- Early Careers
- Technology Program
- Software Engineering

大型项目的开放时间有时比你开始主动找工作更早。

## 第二层：LinkedIn Jobs

适合：

- 搜索 Software Engineer
- Backend Engineer
- Graduate Software Engineer
- Data Engineer
- Machine Learning Engineer
- Internship

不要只依赖 Easy Apply。

看到合适岗位后，可以进一步查看公司官网是否存在官方申请入口。

## 第三层：SEEK

SEEK 是澳洲常见招聘平台之一。

建议使用多个关键词组合，而不是只有 Software Engineer。

例如：

- Junior Software Engineer
- Graduate Developer
- Backend Developer
- Full Stack Developer
- Software Developer
- Data Analyst
- Data Engineer
- QA Automation

不同公司对相似岗位可能使用不同名称。

## 第四层：大学 Career Portal

University Career Portal 经常会出现：

- Campus-specific Opportunity
- Internship
- Graduate Program
- Career Fair
- Employer Event

学生身份本身就是一个可以利用的求职渠道。

## 第五层：Networking

很多机会不是“隐藏岗位”，而是你通过活动更早知道团队、招聘时间或真实岗位需求。

来源可以包括：

- Career Fair
- Tech Meetup
- Alumni Event
- Hackathon
- University Society
- LinkedIn

## Job Alert 应该怎么设置

至少按 Role + Location 建立多个 Alert。

例如 Sydney + Software Engineer、Sydney + Graduate Developer、Sydney + Backend。

## 不要只投职位名称完全匹配的岗位

Software Engineer、Developer、Application Developer、Backend Engineer 和 Graduate Technology 在不同公司可能存在大量能力重叠。

应该阅读 Responsibilities 和 Requirements，而不是只看 Title。

## 建立 Job Tracker

| Company | Role | Source | Date | Stage | Next Action |
| --- | --- | --- | --- | --- | --- |
| A | SWE Graduate | Careers | 10 Mar | Applied | Wait |
| B | Backend Intern | LinkedIn | 12 Mar | OA | Prepare |

真正重要的是知道自己的申请卡在哪个阶段。

## 最后

不要把求职平台当成一个网站。

> 把它们组合成自己的岗位发现系统。
