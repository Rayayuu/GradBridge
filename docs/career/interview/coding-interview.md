# Coding Interview 怎么准备

Coding Interview 不是“刷过多少题”的比赛。

真正需要建立的是识别题型、选择数据结构、推导复杂度、写出正确代码、边写边沟通和测试边界情况。

## 第一阶段：基础数据结构

- Array
- String
- Hash Map
- Set
- Stack
- Queue
- Linked List
- Tree
- Heap
- Graph Basics

不要只会 API，还应该知道常见操作复杂度、什么时候使用，以及常见陷阱。

## 第二阶段：高频 Pattern

- Two Pointers
- Sliding Window
- Prefix Sum
- Binary Search
- Fast / Slow Pointer
- Stack
- Monotonic Stack
- BFS
- DFS
- Backtracking
- Heap / Top K
- Interval
- Dynamic Programming Basics

目标是看到题目以后能够判断它更像哪一种结构。

## 不要马上写代码

先确认 Input、Output、Boundary、Brute Force、可优化的数据结构，以及时间和空间复杂度。

这也是 Live Coding 中非常重要的沟通能力。

## 一个标准流程

Clarify → Brute Force → Optimize → Implement → Test。

手动测试至少覆盖正常 case、极小 case 和边界 case。

## 复杂度一定要会

至少能够解释 O(1)、O(log n)、O(n)、O(n log n) 和 O(n²)。

如果不知道当前复杂度，就很难回答 Can we do better。

## LeetCode 应该刷多少

没有神奇数字。

比数量更重要的是能不能独立复现、理解 Pattern、一周以后还能不能做，以及是否知道为什么这样做。

## OA 与 Live Coding

OA 更强调时间、正确率、测试用例和 Debug。

Live Coding 除了代码，还强调思考过程、沟通、Clarification、Trade-off 和 Testing。

## 面试中卡住怎么办

不要完全沉默。

可以重新确认题意、说出当前思路、指出卡点、尝试小例子，并讨论可能使用的数据结构。

## 一个八周基础节奏

- Week 1: Array / String / Hash Map
- Week 2: Two Pointers / Sliding Window
- Week 3: Stack / Queue / Linked List
- Week 4: Binary Search / Prefix Sum
- Week 5: Tree / DFS / BFS
- Week 6: Heap / Interval
- Week 7: Backtracking / Graph
- Week 8: Mixed Mock Interview

每周都应该保留旧题复习。

## 最后

Coding Interview 更像是在有限时间里展示：我能理解问题、选择合理方法、写出可靠代码，并清楚解释自己的思考过程。
