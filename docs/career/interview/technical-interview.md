# Technical Interview 完整准备框架

很多学生把技术面试等同于 LeetCode。

实际上 Software / Backend / Graduate 岗位还经常考 CS Fundamentals、Project Depth、API、Database、Debugging 和 Engineering Trade-off。

## OOP

至少理解 Encapsulation、Inheritance、Polymorphism、Abstraction、Interface 和 Composition。

不要只背定义，要能够结合实际代码解释为什么这样设计。

## Database

建议掌握：

- Primary Key
- Foreign Key
- Index
- Join
- Transaction
- Normalization
- ACID
- Isolation
- SQL vs NoSQL

你应该能够解释 Index 为什么加速、什么时候存在成本，以及 Transaction 为什么重要。

## HTTP / REST

至少熟悉 HTTP Method、Status Code、Header、Cookie、Session、JWT、REST、Idempotency 和 CORS。

不要只会记 Status Code，也要理解协议背后的语义。

## Authentication / Authorization

Authentication 回答“你是谁”，Authorization 回答“你能做什么”。

常见话题包括 Session、Cookie、JWT、Refresh Token、Role-based Access Control 和 Password Hashing。

## Operating Systems

Early Career 常见范围包括 Process、Thread、Context Switch、Concurrency、Deadlock、Memory、Virtual Memory 和 Synchronization。

## Networking

建议掌握 IP、DNS、TCP、UDP、HTTP、HTTPS、TLS 基础、Port 和 Client / Server。

一个很好的自测问题是：在浏览器输入一个 URL 后发生了什么？

## Caching

至少理解为什么缓存、Cache hit / miss、TTL、Eviction、Cache invalidation 和 Redis 基础。

不要只说 Redis 很快，因为数据在内存里。

## Testing

理解 Unit Test、Integration Test、End-to-End Test、Mock、Test Case 和 Regression。

如果项目里写过测试，一定准备真实例子。

## Git / Engineering Workflow

至少知道 Branch、Commit、Merge、Rebase 基础、Pull Request、Code Review 和 Conflict。

## Project Deep Dive

每个核心项目至少准备：Problem、Architecture、Responsibility、Technical Choice、Challenge、Trade-off、Result 和 Improvement。

如果 CV 写了 Spring Boot、Node.js 或 FastAPI，就应该能够解释 API、Validation、Exception、Database Schema、Authentication、Testing 和 Deployment。

## 不会的问题怎么回答

可以明确说自己没有直接使用过，然后说明当前理解，并基于已知知识继续合理推理。

比编造答案更专业。

## 时间有限时的准备顺序

1. 自己的 Project
2. Database
3. HTTP / REST
4. OOP
5. Authentication
6. Networking
7. OS
8. Testing
9. Cache / Redis
10. 目标岗位专项

## 最后

Technical Interview 不是百科知识竞赛。

真正好的状态是基础概念能解释、项目能讲深、不懂的问题能够合理推理，而且所有写进 CV 的技术都经得起追问。
