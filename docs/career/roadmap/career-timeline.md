# CS 求职时间线

很多学生把求职理解成“岗位开放以后开始投递”。

更有效的做法是：**在岗位开放之前，把大部分准备工作完成。**

## 求职不是单点事件

完整流程通常包括：

1. 能力积累
2. 项目与经历
3. CV / LinkedIn / GitHub
4. 岗位发现
5. 投递
6. OA
7. Coding Interview
8. Technical Interview
9. Behavioral Interview
10. Offer 决策

如果前面几项没有准备好，后面的投递数量再多也很难稳定转化。

## 大一：建立基础

大一重点不是疯狂投实习，而是建立以后能够持续增长的基础：

- 熟练掌握至少一门主要编程语言
- 理解基础数据结构与算法
- 学会 Git / GitHub
- 完成 1 个能够独立解释的小项目
- 建立基本的英文技术阅读能力
- 开始了解不同技术方向

大一结束前，最好能够独立完成一个小项目、把代码放到 GitHub，并解释这个项目解决了什么问题。

## 大二：建立可投递资产

建议重点完成：

- 第一版正式 CV
- 2–3 个能够讲清楚的项目
- 开始 LeetCode / Coding Pattern
- 开始关注 Internship
- 参加 Career Fair、Hackathon、Tech Event
- 优化 LinkedIn
- 尝试第一次真实投递

真实投递可以帮助你发现 CV、算法、项目深度和表达上的真实短板。

## 大三：进入主要申请阶段

申请前最好确认：

- CV 已经可以投递
- LinkedIn 完整
- GitHub 没有明显空白
- 至少有 2 个核心项目能够深入解释
- 算法高频 Pattern 已经覆盖
- Technical Fundamentals 开始系统复习
- Behavioral Story Bank 初步建立

同时建立自己的 Job Tracker：

| Company | Role | Date | Stage | Next Step |
| --- | --- | --- | --- | --- |
| Company A | SWE Intern | 12 Mar | OA | Prepare |
| Company B | Backend Intern | 15 Mar | Applied | Follow up |

比“投了多少”更重要的是每一个阶段的转化率。

## 大四：Graduate / New Grad 主战场

如果计划毕业后直接工作，需要同时处理：

- Graduate Program
- New Grad / Entry-level
- Rolling Hiring
- Internship 转正机会
- Thesis / Capstone
- 面试准备
- 毕业时间与 Work Rights

这时 CV 应逐渐体现 Internship、Engineering Project、Technical Depth 和 Ownership。

## 澳洲 Graduate Program 要提前准备

很多 Graduate Program 会提前开放。

建议提前建立目标公司列表并记录：

- Opening Date
- Closing Date
- Work Rights
- Online Assessment
- Assessment Centre
- Interview Stages
- Location

招聘时间线本身就是求职能力的一部分。

## 每学期做一次求职体检

检查自己的 CV、Project、Interview 和 Job Market 准备是否都在增长。

如果只有成绩越来越高，但长期没有项目、实习、面试能力和市场反馈，就应该重新分配时间。

## 一个可执行的求职季节奏

- 每周 2 次 Coding Practice
- 每周 1 次 Technical Fundamentals
- 每周 1 次 Project Review
- 每周 1 次 CV / LinkedIn 优化
- 固定时间搜索与投递岗位
- 每周至少复盘一次面试或 Behavioral Story

## 最后

你不需要等到“准备好了”才开始求职。

> 一边准备，一边进入市场，一边根据真实反馈修正。

求职不是毕业前的一场考试，而是一套持续迭代的系统。
