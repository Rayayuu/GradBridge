# 第一份 CS 实习怎么找

第一份实习通常最难，因为你还没有上一段实习来证明自己。

这时真正能够支撑你的，通常是课程基础、项目、GitHub、技术能力、沟通和学习速度。

## 核心问题不是“有没有经验”

更重要的问题是：

> 当没有正式工作经历时，我还能拿什么证明自己？

答案通常是项目和可验证的技术输出，例如：

- 完整 Web App
- Backend API
- 数据分析项目
- AI / ML 项目
- 开源贡献
- Hackathon 项目
- 课程项目中真正承担的重要模块

## 什么时候应该开始找

当你满足下面大部分条件时，就可以开始：

- 有一版一页 CV
- 有至少 1–2 个能够解释的项目
- 会基本 Git
- 能完成基础 Coding Question
- 能介绍自己的技术方向
- 能解释为什么申请这个岗位

准备和投递可以并行。

## 第一份实习可以投什么

不要只盯最热门的大公司。

- Software Engineer Intern
- Backend Intern
- Frontend Intern
- Full-stack Intern
- QA Automation Intern
- Data Intern
- AI / ML Intern
- DevOps / Cloud Intern
- Research Assistant
- Startup Engineering Intern

第一段经历的重要价值，是帮助你第一次进入真实工程环境。

## 没有 Internship 时 CV 怎么写

重点放在 Education、Technical Skills、Projects、Leadership 和 Relevant Experience。

弱写法：

> Built a web application using React.

更好的写法：

> Built a React + Node.js task platform with JWT authentication and PostgreSQL persistence, implementing REST APIs for user and task workflows.

## 项目数量不是越多越好

三个浅项目通常不如两个讲得很深的项目。

面试时你可能会被追问：

- 为什么选这个技术？
- 数据库怎么设计？
- Authentication 怎么做？
- 遇到过什么 Bug？
- 性能瓶颈在哪里？
- 如果重做会改什么？
- 团队里你负责哪部分？

## 没有回复怎么办

如果完全没有 OA / Interview，优先检查 CV、岗位匹配、Work Rights、项目表达和申请时机。

如果有 OA 但过不了，优先补 Coding Pattern、时间管理和 Debug。

如果有 Interview 但没有下一轮，优先补 Project Depth、Technical Fundamentals、Communication 和 Behavioral。

## Networking 怎么做

Networking 不等于直接向陌生人索要 Referral。

更自然的方式包括 Career Fair、Tech Meetup、Hackathon、Alumni Event、University Society 和 LinkedIn Professional Conversation。

目标是获得行业信息、团队信息、招聘时间、岗位理解和长期连接。

## 第一份实习前应该准备什么

Coding 至少覆盖 Array、String、Hash Map、Two Pointers、Stack、Queue、Linked List、Binary Search、Tree、BFS 和 DFS。

Fundamentals 至少覆盖 OOP、Database、HTTP、REST、Git、Testing 和 Basic Networking。

同时准备两个核心项目和一组真实 Behavioral Story。

## 第一份实习真正应该获得什么

- 读别人代码
- 使用 Git Workflow
- 接受 Code Review
- Debug 真实系统
- 与 PM / Engineer 沟通
- 理解 Deadline
- 对自己的代码负责

第一份实习本质上是从学生能力到职业能力的第一次转换。
