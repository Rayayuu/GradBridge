# 悉尼 CS 求职完整入门

在悉尼读 CS，一个常见误区是：等课程全部学完以后再开始找工作。

现实中更有效的路线通常是边学习、边做项目、边了解市场、边申请。

## 可以搜索哪些岗位

不要只搜索 Software Engineer。

还可以关注：

- Software Developer
- Backend Engineer
- Full Stack Developer
- Frontend Engineer
- Graduate Developer
- Technology Graduate
- Data Engineer
- Data Analyst
- Machine Learning Engineer
- QA Automation
- Cloud / DevOps

## 悉尼学生的优势

本地就读意味着你可以利用：

- University Career Fair
- Employer Event
- Hackathon
- Tech Meetup
- Alumni
- Student Society
- In-person Interview
- Local Internship

这些机会不应该等毕业前一个学期才开始使用。

## 第一份经历从哪里来

第一份经历不一定来自大型科技公司。

Startup、Small Company、Research Project、Automation、QA、Data、University Project 和 Open Source 都可能成为下一次申请的证据。

## 悉尼求职建议建立三层公司池

### Tier A：非常想去

提前研究公司、团队、招聘时间和面试形式。

### Tier B：高度匹配

主要投递池。

### Tier C：探索机会

帮助获得真实市场反馈。

目的不是给公司贴高低标签，而是管理自己的申请时间。

## 每周执行节奏

- 固定搜索岗位
- 更新 Job Tracker
- 进行 Coding Practice
- 复习 Technical Fundamentals
- 深挖一个 Project
- 参加一个 Career / Tech Activity

## 不要只盯大厂

第一份工作最重要的价值之一，是进入真实 Engineering Environment。

你会开始接触：

- Existing Codebase
- Git Workflow
- Code Review
- Ticket
- Testing
- Deployment
- Team Communication

## 本地项目要能解释

如果你有 University Capstone、Honours、Hackathon 或 Personal Project，应该能够把它们转化成工程证据。

面试官通常更关心你到底负责什么，而不是项目名字有多高级。

## 最后

悉尼 CS 求职不是一场毕业时突然开始的考试。

> 最好从还在学校的时候，就开始进入真实市场。
