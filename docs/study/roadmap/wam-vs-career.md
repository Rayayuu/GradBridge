# WAM 与求职怎么平衡

> 成绩重要，但求职竞争力不是由成绩单单独决定的。

很多海外 CS 学生会经历同一个问题：

> 我应该继续冲 WAM，还是把时间拿去做项目、刷题和找实习？

这不是一个简单的二选一问题。

更合理的思考方式是：

```text
Academic Performance
+
Technical Skills
+
Projects
+
Experience
+
Interview Ability
=
整体竞争力
```

---

## WAM 为什么重要

成绩能够体现一些很重要的能力：

- 学习能力
- 基础知识掌握程度
- 长期稳定性
- Academic Discipline

在某些场景下，成绩还可能直接影响：

- Honours
- Scholarship
- Master / PhD
- 部分 Graduate Program
- 某些竞争性项目

因此，完全忽视成绩通常不是好策略。

---

## 为什么只追求成绩也不够

Software Engineering 和很多技术岗位最终仍然会关注：

- 你能不能写代码
- 能不能做项目
- 能不能解决问题
- 是否有工程能力
- 是否理解基础
- 能不能通过面试

如果一个学生拥有非常高的 WAM，但没有：

- GitHub
- Project
- Internship
- Coding Interview 准备

那么求职时仍然可能遇到明显短板。

---

## 真正需要考虑的是边际收益

假设你已经有一个不错的成绩。

为了再提高少量 WAM，你可能需要投入大量额外时间。

这时应该问：

> 这些时间如果用来完成一个核心项目、申请 Internship 或准备面试，会不会产生更高收益？

这就是机会成本。

---

## 不同目标需要不同权重

### 如果目标是 Software Engineering

通常需要同时保证：

- 成绩不成为明显短板
- 项目有内容
- Coding 能力足够
- 有实习或工程经历更好
- 面试准备完整

### 如果目标是 Research / PhD

Academic Performance、Research Experience、Honours / Thesis 的权重通常会明显提高。

### 如果目标是 Master

需要关注目标项目具体的 Academic Requirement，同时兼顾能够支撑申请材料的项目、Research 或实习。

因此不存在所有人通用的完美比例。

---

## 一个实用判断框架

每学期可以检查四个维度。

### 课程

- 有没有挂科风险？
- 核心课程是否真正理解？

### 技术

- 主技术方向有没有继续增长？

### 项目

- 有没有一个能用于 CV 和面试的项目？

### 求职

- 如果今天看到一个合适岗位，我能不能投？

如果某一个维度长期接近零，就应该调整。

---

## 推荐的优先级思路

第一层：避免明显学术风险。

第二层：保证核心课程真正学会。

第三层：把剩余时间投入长期职业资产。

所谓职业资产包括：

- 项目
- Internship
- GitHub
- LeetCode
- Interview
- Networking

它们的特点是可以跨学期积累。

---

## 一个典型错误：为了 1–2 分牺牲所有项目时间

这不是说 1–2 分没有价值。

而是要看你目前最缺什么。

如果你的情况是：

```text
成绩已经稳定
项目 = 0
实习 = 0
面试准备 = 0
```

那么继续把全部额外时间压在成绩上，很可能让能力结构越来越失衡。

---

## 另一个极端：完全不管课程

“公司只看能力”也不应该被理解成可以无视大学课程。

因为很多课程本身就是之后技术能力的基础。

例如：

- Data Structures
- Algorithms
- Database
- Operating Systems
- Computer Networks

这些内容以后仍然会回来。

---

## 每周怎么分配

不建议死记一个固定百分比。

更实际的方法是先锁定不可避免的课程任务，然后给长期能力固定时间。

例如：

```text
课程与 Assignment
      ↓
固定项目时间
      ↓
固定算法时间
      ↓
求职 / CV / Networking
```

即使每周只有几个小时，也比考试结束后再重新开始更稳定。

---

## 考试周和招聘季发生冲突怎么办

优先提前准备。

真正的问题往往不是那一周时间不够，而是前几个月什么都没有准备。

如果：

- CV 提前写好
- 项目提前完成
- LeetCode 持续进行
- Job Tracker 已经建立

招聘季的压力会明显下降。

---

## 最后的判断标准

每学期结束可以问自己：

1. 我的成绩是否足以支撑下一阶段目标？
2. 我的技术能力有没有实际增长？
3. 我有没有新的项目或经历可以写进 CV？
4. 我离目标岗位更近了吗？

如果只有第一个问题越来越好，其他三个长期没有变化，就值得重新分配时间。

**WAM 是竞争力的一部分，而不是竞争力的全部。**
