# 大一应该做什么

> 大一的目标不是提前学完整个计算机科学，而是建立一套以后能够持续增长的基础。

刚进入 CS 时最容易出现两个极端：

- 觉得自己什么都不会，所以只跟着课程走
- 看别人刷题、实习、做 AI，于是什么都想同时开始

更合理的方法是把第一年拆成几个明确目标。

```text
适应大学
→ 学会编程
→ 建立 CS 基础
→ 学会 Git
→ 完成第一个项目
→ 初步了解求职
```

---

## 大一结束时，你应该达到什么状态

理想情况下，大一结束时你应该能够：

- 熟练使用至少一门主要编程语言
- 理解基础数据结构和算法
- 使用 Git 和 GitHub
- 独立完成一个小型项目
- 阅读基本技术文档
- Debug 自己的代码
- 开始接触 LeetCode
- 知道 Backend、AI、Data、Security 等方向大概在做什么

你不需要已经成为工程师。

但应该开始从“只会完成作业”走向“能够自己做东西”。

---

## 第一阶段：先适应大学，而不是急着卷

海外大学与高中最大的差别之一，是很多事情不会有人持续提醒你。

你需要开始自己管理：

- Lecture
- Tutorial / Lab
- Assignment
- Quiz
- Group Project
- Exam
- Personal Project
- 求职准备

建议尽早形成自己的每周系统。

例如：

```text
课程任务
      ↓
本周复习
      ↓
编程练习
      ↓
个人项目
      ↓
周末回顾
```

不要等考试周才第一次整理课程。

---

## 第二阶段：真正学会一门语言

大一阶段最重要的不是语言数量。

如果学校主要使用 Java，就先把 Java 学扎实。

如果主要使用 Python，也可以先围绕 Python 建立基础。

至少需要逐渐掌握：

- Variable
- Condition
- Loop
- Function
- Array / List
- Class
- Object
- Inheritance
- Exception
- File I/O
- 基础 Debug

你的判断标准不是：

> “我看过这个语法。”

而是：

> “不给我模板，我能不能自己写出来？”

---

## 第三阶段：把数据结构学明白

第一年常见的数据结构包括：

- Array
- ArrayList / List
- Linked List
- Stack
- Queue
- HashMap
- Set
- Tree 基础

学习时不要只背定义。

每个数据结构至少问四个问题：

1. 它解决什么问题？
2. 常见操作是什么？
3. 时间复杂度是多少？
4. 什么场景下应该使用它？

例如 HashMap 的价值不是“面试会考”。

而是它能够帮助你快速通过 Key 找到 Value。

---

## 第四阶段：尽早学 Git 和 GitHub

很多学生直到 Group Project 才第一次认真使用 Git。

其实大一就应该开始。

至少掌握：

```text
git clone
git status
git add
git commit
git pull
git push
git branch
```

并理解：

- Repository
- Commit
- Branch
- Merge
- Remote
- Conflict

从第一个个人项目开始，就把代码放在 GitHub。

你的 GitHub 不需要一开始就很漂亮。

重要的是形成长期使用习惯。

---

## 第五阶段：完成第一个真正的项目

不要一开始就挑战“大型 AI 平台”或者“完整电商系统”。

第一个项目最重要的是完整。

例如：

- Todo List
- Expense Tracker
- Course Planner
- Personal Blog
- Simple REST API
- Weather Dashboard
- Study Tracker

一个完整的小项目至少应该经历：

```text
想法
→ 功能设计
→ 编码
→ Debug
→ Git
→ README
→ 完成
```

### README 至少写什么

- 项目是什么
- 为什么做
- 使用什么技术
- 如何运行
- 主要功能
- 后续可以改进什么

这已经比单纯上传代码强很多。

---

## 第六阶段：开始 LeetCode，但不要被题数绑架

大一适合从基础题型开始。

推荐顺序：

```text
Array
→ String
→ HashMap
→ Two Pointers
→ Stack
→ Queue
→ Linked List
→ Binary Search
```

这个阶段最重要的是理解模式。

你应该练习解释：

- 为什么这样做
- 时间复杂度是多少
- 空间复杂度是多少
- 有没有边界情况

而不是追求“刷了 300 道”。

---

## 第七阶段：开始了解不同技术方向

大一不需要立刻决定职业方向。

但可以开始观察：

### Backend

如果你喜欢：

- API
- Database
- 系统逻辑
- Server
- 分布式系统

可以继续了解 Backend。

### AI / Machine Learning

如果你喜欢：

- Python
- 数据
- 模型
- 数学
- 实验

可以开始了解 AI / ML。

### Data

如果你喜欢：

- SQL
- 数据分析
- Visualization
- Pipeline

可以了解 Data Engineering / Analytics。

### Security

如果你喜欢：

- Network
- Web Security
- Vulnerability
- Reverse Engineering

可以继续了解 Security。

探索可以广，但真正学习时最好逐渐形成主线。

## 一个比较现实的每周分配

不需要每天学习十几个小时。

在课程正常进行的情况下，可以尝试：

| 内容 | 建议 |
| --- | --- |
| 课程 | 优先完成并理解核心内容 |
| 编程 | 每周持续练习 |
| LeetCode | 少量、持续 |
| 项目 | 每周固定时间推进 |
| GitHub | 跟随项目自然维护 |
| 技术探索 | 周末适量进行 |

核心不是每天全部做。

而是不要连续几个月完全停止其中某一条重要主线。

## 大一最常见的错误

### 只追求 WAM / GPA

成绩重要，但如果一年结束后完全不会独立做项目，后面仍然要补。

### 同时学习太多语言

Java、Python、C++、JavaScript 全学一点，往往意味着没有一个真正熟练。

### 复制 Tutorial 项目

跟着教程做项目可以入门，但最终需要离开教程自己做一次。

### 过早焦虑实习

可以了解 Internship，但第一年的核心仍然是基础能力。

### GitHub 只有 Assignment

学校作业并不等于完整个人技术作品。

## 大一结束 Checklist

- [ ] 熟练使用至少一门编程语言
- [ ] 理解常见基础数据结构
- [ ] 可以独立 Debug 基础程序
- [ ] 会使用 Git 和 GitHub
- [ ] 有至少一个完整个人项目
- [ ] 项目有基本 README
- [ ] 开始做基础 LeetCode
- [ ] 对主要 CS 职业方向有初步认识
- [ ] 建立自己的学习和任务管理方式
