# Inspection、Lease 与 Bond Checklist

这份 Checklist 适合真正去看房和准备签约时使用。

## Inspection：房间

- [ ] 房间尺寸符合 Listing
- [ ] Window 可以正常打开关闭
- [ ] Door / Lock 正常
- [ ] Natural Light 可以接受
- [ ] 没有明显 Mould / Damp
- [ ] 墙面和地板状态记录清楚
- [ ] Storage 足够
- [ ] 手机信号正常

## Inspection：公共区域

- [ ] Kitchen 状态
- [ ] Stove / Oven
- [ ] Fridge 是否包含
- [ ] Laundry
- [ ] Bathroom
- [ ] Hot Water
- [ ] Building Access
- [ ] Garbage Room
- [ ] Bicycle / Parking Requirement

## 周边环境

- [ ] 晚上是否过于吵
- [ ] 最近公共交通
- [ ] 最近 Grocery
- [ ] 晚上回家的路线
- [ ] 到学校 Door-to-door Time

## Lease 前

- [ ] 地址正确
- [ ] 租客姓名正确
- [ ] Weekly Rent 正确
- [ ] Lease Term 正确
- [ ] Included Furniture 写清楚
- [ ] Utilities 写清楚
- [ ] Special Terms 已阅读
- [ ] Payment Method 清楚

## NSW 当前签约材料

在适用的 NSW Residential Tenancy 中，租客签约或入住前通常应收到：

- Tenant Information Statement
- Proposed Tenancy Agreement
- Condition Report
- Strata By-laws（如适用）
- Rental Bonds Online Invitation

## Bond

截至 2026 年 9 月：

- Residential Bond 上限通常为 4 周 Rent
- Rental Bonds Online 由 NSW Fair Trading 管理
- Agent / Landlord 应提供在线 Lodgement 选项

不要把 Bond 当成普通“押金转给某个人就结束”。

## Rent in Advance

当前 NSW 规则下，最多可以要求 2 周 Rent in Advance。

例如：

```text
Bond
≠
Rent in Advance
```

两项必须分开理解。

## Condition Report

这是非常值得认真处理的一步。

建议：

1. 对照每一个房间检查
2. 不同意的描述直接补充
3. 拍摄带时间记录的照片
4. 保存提交版本

## Red Flags

- 没看房就催促大额付款
- 地址 / Agent 信息对不上
- 要求非常规支付方式
- 不愿提供书面 Agreement
- Listing 与现场明显不一致
- 对 Bond 去向解释不清楚

## 最后

> Inspection 是检查房子，Lease 是检查合同，Bond 是检查钱去了哪里。这三步不要混成一个步骤。
