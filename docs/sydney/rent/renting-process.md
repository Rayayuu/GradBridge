# 悉尼学生租房完整流程

悉尼租房最重要的不是“找到最便宜的房子”。

而是找到一个：

> 价格、通勤、房屋状态、合同和生活便利都能长期接受的方案。

## Step 1：先定真实预算

不要只计算 Weekly Rent。

还要考虑：

- Electricity
- Gas
- Internet
- Water 是否包含
- Transport
- Furniture
- Moving Cost

真正应该比较的是 Total Living Cost。

## Step 2：确定通勤边界

先确定你能够接受：

- 到学校的 Door-to-door Time
- 是否接受 Transfer
- 是否需要夜间公共交通
- 是否可能去 CBD / Internship

## Step 3：建立房源 Shortlist

不要看到一个房子就立刻申请。

建议记录：

| Field | Example |
| --- | --- |
| Weekly Rent | $X / week |
| Area | Redfern |
| Commute | 20 min |
| Furnished | Yes / No |
| Bills | Included / Excluded |
| Lease | Fixed / Other |
| Inspection | Date |
| Application | Status |

## Step 4：Inspection

现场重点看：

- 房间真实尺寸
- Natural Light
- Ventilation
- Noise
- Mould / Damp
- Window / Door
- Kitchen
- Bathroom
- Storage
- Building Access
- 手机信号

不要只看 Listing Photo。

## Step 5：Application

准备常见申请材料，例如：

- Identity
- Student / Employment Information
- Rental History
- Income / Financial Evidence
- References

不同 Agent 要求可能不同。

提交敏感文件前确认平台和中介身份。

## Step 6：成功以后不要立刻付款

先确认：

- Property Address
- Landlord / Agent
- Weekly Rent
- Lease Term
- Included Items
- Bills
- Payment Instructions

对于异常私人转账、现金要求或“必须马上付款否则没房”的情况保持谨慎。

## Step 7：Lease

签署前逐条看 Agreement。

不要因为中介催促就跳过：

- Rent
- Term
- Special Terms
- Included Furniture
- Utilities
- Repair / Contact Information

## Step 8：Bond

截至 2026 年 9 月，NSW Residential Rental Bond 通常不能超过 4 周租金。

Rental Bonds Online 是 NSW Fair Trading 的官方 Bond 管理服务。

房东或 Agent 应向新租客提供使用 Rental Bonds Online 的选项。

## Step 9：Rent in Advance

NSW 当前规则下，房东或 Agent 最多可以要求 2 周 Rent in Advance。

Rent in Advance 和 Bond 是两件不同的事。

## Step 10：Condition Report

入住前认真检查 Condition Report。

如果实际状态与 Report 不一致：

- 写清楚
- 拍照
- 拍视频
- 保存时间记录

## Step 11：Move-in Evidence

入住第一天建议记录：

- Wall
- Floor
- Window
- Kitchen
- Bathroom
- Furniture
- Appliance

这些资料未来退租时可能非常重要。

## 官方规则提醒

NSW 租赁法规会调整。

涉及 Bond、Rent Increase、Termination、Repair、Pet 和 Dispute 时，应以 NSW Fair Trading / NSW Government 当前规则为准。

## 最后

> 租房真正值得花时间的阶段，是付款和签字之前，而不是出问题之后。
