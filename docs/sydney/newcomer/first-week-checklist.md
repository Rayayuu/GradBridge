# 悉尼新生第一周 Checklist

刚到悉尼最容易出现的问题，不是“完全不知道做什么”，而是几十件小事同时出现。

这份 Checklist 的目标是把最重要的事情按优先级排好。

## 落地当天

- [ ] 确认临时或长期住宿可以正常入住
- [ ] 手机有稳定网络
- [ ] 保存住址、房东 / 中介和紧急联系人
- [ ] 确认从机场到住宿地点的交通方式
- [ ] 准备可以正常使用的支付方式
- [ ] 把护照、签证和学校文件做电子备份

## 交通

- [ ] 了解最近的 Train / Metro / Bus / Light Rail
- [ ] 准备 Opal 或可用的 contactless payment
- [ ] 学会使用 Trip Planner
- [ ] 第一次通勤前提前查路线
- [ ] 确认自己是否符合 Concession Eligibility

> 使用银行卡或手机 contactless 时，建议一次 Journey 始终使用同一张卡或同一设备完成 tap on / tap off。

## 手机和网络

- [ ] 有一个稳定的澳洲手机号
- [ ] 修改学校、银行等重要账户联系方式
- [ ] 确认住宿 Wi-Fi / NBN 是否已经可用
- [ ] 开启重要账户 Two-Factor Authentication

## 银行和支付

- [ ] 准备日常使用的澳洲 Bank Account
- [ ] 确认 Debit Card / Mobile Wallet 可正常使用
- [ ] 保存 BSB 和 Account Number
- [ ] 不要把银行卡、验证码或网银密码发给任何人

## 学校

- [ ] Student ID / Campus Access 正常
- [ ] 学校 Email 可以登录
- [ ] Timetable 已确认
- [ ] Canvas / LMS 可以访问
- [ ] 知道主要教学楼和 Library 在哪里
- [ ] 知道 International Student Support 在哪里找

## 医疗

- [ ] 保存自己的 OSHC / Insurance 信息
- [ ] 知道保险 App / Member Number 如何使用
- [ ] 了解附近 GP / Medical Centre 的基本就医方式
- [ ] 保存紧急号码 000

不同国籍、签证和保险安排可能对应不同 Medicare / RHCA Eligibility，不要默认自己的情况和其他同学一样。

## 如果准备兼职或实习

- [ ] 确认自己的 Visa Work Conditions
- [ ] 需要工作时了解 TFN
- [ ] 准备澳洲手机号和银行信息
- [ ] 不接受要求先支付大额费用的“工作机会”

## 第一周结束前

- [ ] 已经完成一次学校通勤
- [ ] 知道最近的超市
- [ ] 知道最近的 Pharmacy
- [ ] 建立基本每周预算
- [ ] 所有重要文件已经云端备份
- [ ] 至少认识一两个可以联系的同学

## 不需要第一周解决所有事情

以下事情可以慢慢处理：

- 找“最完美”的长期住房
- 买齐所有生活用品
- 立刻参加所有社团
- 立刻规划整个大学四年

先让自己的生活稳定下来。
