# 悉尼生活基础 Setup

刚到澳洲以后，有几个账户会逐渐成为你整个留学生活的基础设施。

## 澳洲手机号

手机号通常会被用于：

- 银行
- Two-Factor Authentication
- 房屋申请
- 快递
- 求职
- 学校联系

所以相比追求最便宜套餐，更重要的是保证号码稳定并长期保留。

## 银行账户

日常通常需要能够：

- 收款
- 转账
- 使用 Debit Card
- 使用 Mobile Wallet
- 查看 Transaction History

租房申请、工资和日常支付都会使用。

## Account Security

建议尽早：

- 开启 2FA
- 使用 Password Manager
- 不复用重要密码
- 不向任何人提供短信验证码
- 对陌生电话中的“银行 / 政府 / 快递”保持警惕

## 医疗与保险

International Student 应该保存好自己的 OSHC 或其他适用保险信息。

至少知道：

- Provider
- Member Number
- App / Website
- Claim 流程
- Emergency Contact

一些来自特定国家的人可能符合 Reciprocal Health Care Agreement 或其他 Medicare 条件，但 Eligibility 需要根据个人情况确认。

## GP 和 Emergency

普通健康问题通常可以先了解 GP / Medical Centre。

真正紧急情况使用 000。

不要把普通 GP、Urgent Care 和 Emergency Department 完全混在一起。

## 如果准备工作

如果准备兼职、Internship 或 Graduate Role，需要进一步了解：

- Visa Work Conditions
- TFN
- Superannuation
- Payslip
- Employment Contract

具体规则具有时效性，应以 Australian Government 当前规定为准。

## 建议建立一个 Personal Admin Folder

例如：

```text
Australia/
├── University/
├── Visa/
├── Housing/
├── Bank/
├── Health/
├── Employment/
└── Tax/
```

重要文件同时保留安全的 Cloud Backup。

## 最后

> 落地阶段把这些基础账户整理好，之后租房、工作、看医生和处理学校事务都会轻松很多。
