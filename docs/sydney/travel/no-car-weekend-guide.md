悉尼留学生不开车周末怎么玩

没有车，不代表悉尼周末只能待在 CBD。

但也不是所有“悉尼周边景点”都适合纯公共交通。

真正要判断的是：

这个目的地的 Public Transport Friction 有多高？

Level 1：低摩擦

通常特点：

公共交通可以直接到主要区域
Transfer 少
回程简单
不依赖最后一段 Taxi

最适合第一次自己出去。

Level 2：需要规划

通常特点：

Train + Bus
Ferry + Bus
班次间隔较长
需要控制返程时间

适合提前规划。

Level 3：不开车明显不方便

通常可能有：

最后一段交通弱
景点之间距离远
周末班次少
Return Trip 不灵活

不是不能去，而是公共交通成本可能比较高。

出发前检查五件事
第一段交通
Return Service
Transfer 次数
Walking Distance
最晚安全返程时间

另外，周末交通可能存在临时调整。

出发当天重新查看 Trip Planner 是更可靠的做法。

为什么有些热门目的地没有优先推荐

一些非常漂亮的区域，对纯公共交通学生来说可能存在：

最后一公里困难
景点分散
时间利用率低

GradBridge 的目标不是列出最多景点，而是筛选真正适合学生周末执行的路线。
