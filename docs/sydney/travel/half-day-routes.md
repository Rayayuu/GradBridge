# 悉尼留学生 0.5 天周末路线

不是每个周末都需要安排一整天旅行。

课程忙的时候，半天路线反而更容易长期执行。

路线 A：Circular Quay → The Rocks → Barangaroo

适合：

City Walk
第一次认识 Sydney Harbour
下午到晚上

可以重点体验：

Harbour
Old Sydney Street
Waterfront
Sunset / Night View
路线 B：Bondi → Coastal Walk

适合：

Walking
海边
Study Break
好天气

不要为了完成“整条路线”勉强自己。

根据体力和天气决定折返点。

路线 C：Manly

公共交通本身就可以成为路线的一部分。

适合：

Ferry Experience
Beach
Cafe
Sunset
路线 D：Newtown → Enmore

适合：

Food
Cafe
Street Walk
和朋友轻松见面

如果你住在 USYD 周边，这种路线几乎不需要额外旅行准备。

路线 E：Darling Harbour → Barangaroo

适合：

傍晚散步
Dinner
Night Walk
怎么选

如果只剩 3–5 小时：

不要追求“去很远”
而是降低交通时间
增加真正停留时间
天气

Coastal Walk 和 Sunset 类路线受天气影响较明显。

出发前看：

Weather
Sunset Time
Return Transport
最后

半日路线的价值，就是让“出去走走”不再需要提前一周计划。
