## 🌉 关于 GradBridge

GradBridge 是一个面向海外 CS 学生的开源成长知识库。

我们希望把一个学生从进入大学，到找到第一份技术工作的过程中真正需要的信息，整理到同一个地方。

GradBridge 关注的是一条完整成长路径：

```text
进入大学
   ↓
规划学习
   ↓
建立技术能力
   ↓
完成项目
   ↓
准备 CV
   ↓
Internship / Graduate
   ↓
OA / Interview
   ↓
第一份技术工作
```

## 💻 本地运行

安装依赖：

```bash
pnpm install
```

启动开发服务器：

```bash
pnpm exec vitepress dev
```

默认地址：

```text
http://localhost:5173/
```

## 📌 内容原则

**实用优先**：每一页都应该解决真实问题。

**免费内容完整**：免费内容不是付费产品的残缺预览。

**时效信息透明**：招聘、签证、租房和交通等内容尽量注明 Last Updated 与 Source。

**尊重 Academic Integrity**：不提供当前 Assignment、Quiz、Exam 答案或未授权学校资料。
